## 🛠️ Tecnologías Utilizadas

* **HTML5:** Marcado semántico y estructura del documento web accesible.
* **CSS3:** Variables nativas (design tokens), efectos de *glassmorphism*, gradientes personalizados y animaciones fluidas.
* **JavaScript (ES6+):** Lógica interactiva del cliente, renderizado dinámico de proyectos mediante objetos y *Intersection Observer API* para efectos al desplazarse (*scroll reveal*).
* **Bootstrap 5 (v5.3.3) & Bootstrap Icons:** Sistema de grillas responsivas, componentes de navegación, utilidades y tipografía iconográfica.
* **Git:** Control de versiones distribuido, convención de *Conventional Commits* y flujo de trabajo con ramas (*feature branching*).
* **GitHub & GitHub Pages:** Alojamiento de código fuente y despliegue continuo de la aplicación web.

## 📋 Control de Versiones e Instalación Local

Para clonar y revisar este proyecto en tu entorno local:

```bash
# 1. Clonar el repositorio
git clone https://github.com/lezana07/portafolios-web.git

# 2. Entrar a la carpeta
cd portafolios-web

# 3. Abrir en el navegador (o mediante Live Server)
start index.html
```
